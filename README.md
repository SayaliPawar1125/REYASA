# REYASA – Full Stack E-Commerce Website

**Created with passion. Worn with love.**

REYASA is a full-stack e-commerce web application developed to provide a smooth and user-friendly online shopping experience. Customers can explore products, view product details, select sizes, manage their wishlist and shopping cart, and place orders through secure online payments.

The application also includes an admin panel to manage products, orders, customer enquiries, and other website content.

## ✨ Key Features

### Customer Features
- User registration and login
- Google authentication
- Browse and explore product collections
- View product details, images, sizes and stock availability
- Add products to wishlist
- Add products to shopping cart
- Manage cart items
- Check delivery availability using PIN code
- Secure online payment using Razorpay
- Place and track orders
- Forgot password and OTP verification

### Admin Features
- Admin authentication and dashboard
- Add, update and manage products
- Manage product images, sizes and stock
- Manage trending products
- View and manage customer orders
- Update order statuses
- Manage customer enquiries and replies
- Manage delivery PIN codes
- Manage homepage videos and website content
- Manage website footer and expenses

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/SayaliPawar1125/REYASA.git
```

### 2. Frontend Setup

```bash
cd "REYASA/Reyasa Frontend/reyasa-frontend"
npm install
npm run dev
```

Frontend runs at:

`http://localhost:5173`

### 3. Backend Setup

Open the backend folder in IntelliJ IDEA.

Configure your MySQL database and application environment variables.

Run the Spring Boot application.

Backend runs at:

`http://localhost:8080`

### 4. Database Configuration

- Install MySQL.
- Create the REYASA database.
- Configure database connection details.
- Set the required environment variables.
- Start the Spring Boot backend.

### 5. Environment Variables

Configure the required credentials securely, including:

- MySQL database URL, username and password
- Razorpay Key ID and Secret Key
- Email username and app password
- Google authentication credentials, if configured

**Important:** Never upload actual passwords, API secrets or `.env` files to GitHub.
